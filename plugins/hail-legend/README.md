# Hail size quick legend

A pocket reference for spotter reports: hail sizes in **inches** (or *mm* when your distance
unit is km) next to the everyday object they match — from a *pea* to a *softball*.

## What you get

- A floating panel with 13 reference sizes, colour-coded:
  - grey / green — below severe
  - yellow — **1″ and up is severe** (quarter)
  - orange / red — 1.5″–2.5″
  - purple — 2.75″ and up (baseball and bigger)
- **Hail in view**: the radar-estimated maximum hail size (`max_size`) of storm cells inside the
  current map view, biggest first. Updates when you pan and every 2 minutes.

> Radar hail sizes are estimates. Report what you measure, not what radar shows.
